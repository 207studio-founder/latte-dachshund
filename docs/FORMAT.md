# 스프라이트 형식

이 에셋 팩은 Codex 데스크톱의 custom pet v2 형식에 맞춘 래스터 스프라이트 시트와 메타데이터로 구성됩니다.

## 파일과 크기

| 항목 | 값 |
| --- | --- |
| 이미지 파일 | `spritesheet.webp` |
| 이미지 형식 | 투명 배경을 포함한 WebP |
| 전체 크기 | 1536 × 2288 픽셀 |
| 격자 | 8열 × 11행 |
| 한 프레임 크기 | 192 × 208 픽셀 |
| 메타데이터 | `pet.json` |
| 스프라이트 버전 | `2` |

행과 열은 모두 **0부터** 셉니다. 프레임의 왼쪽 위 좌표는 `x = 열 × 192`, `y = 행 × 208`입니다. 각 동작은 해당 행의 0열에서 시작하며, 아래 표에 표시된 프레임 수까지만 사용합니다.

## 행별 배치

| 행 | 동작 | 프레임 수 | 사용 열 | 설명 |
| --- | --- | --- | --- | --- |
| 0 | `idle` | 6 | 0–5 | 기본 대기 동작. 6열에는 별도의 중립 프레임이 있습니다. |
| 1 | `running-right` | 8 | 0–7 | 오른쪽으로 달리기 |
| 2 | `running-left` | 8 | 0–7 | 왼쪽으로 달리기 |
| 3 | `waving` | 4 | 0–3 | 앞발 흔들기 |
| 4 | `jumping` | 5 | 0–4 | 점프하기 |
| 5 | `failed` | 8 | 0–7 | 실패 상태 동작 |
| 6 | `waiting` | 6 | 0–5 | 기다리는 동작 |
| 7 | `running` | 6 | 0–5 | 제자리에서 작업 중인 동작 |
| 8 | `review` | 6 | 0–5 | 검토 중인 동작 |
| 9 | 시선 방향 0–7 | 8 | 0–7 | 0°부터 157.5°까지 |
| 10 | 시선 방향 8–15 | 8 | 0–7 | 180°부터 337.5°까지 |

0행의 6열은 `idle`의 6프레임 애니메이션에 포함하지 않습니다. 그 밖에 사용 열로 지정되지 않은 칸도 동작 프레임에 포함하지 않습니다.

## 시선 방향

각도는 화면의 **위쪽을 0°**로 두고 **시계 방향**으로 증가합니다. 따라서 오른쪽은 90°, 아래쪽은 180°, 왼쪽은 270°입니다. 16개 방향 사이의 간격은 22.5°입니다.

| 열 | 9행 | 10행 |
| --- | --- | --- |
| 0 | 0° | 180° |
| 1 | 22.5° | 202.5° |
| 2 | 45° | 225° |
| 3 | 67.5° | 247.5° |
| 4 | 90° | 270° |
| 5 | 112.5° | 292.5° |
| 6 | 135° | 315° |
| 7 | 157.5° | 337.5° |

위쪽을 향하는 두 중간 시선은 좌우 차이가 미묘할 수 있습니다. 16개 시선을 각도 순서대로 연결한 루프는 확인했으며, 이를 살펴볼 수 있는 미리보기는 [look-around.gif](../previews/look-around.gif)입니다.

## 메타데이터

`pet.json`과 `spritesheet.webp`는 같은 폴더에 둡니다.

```json
{
  "id": "latte-dachshund",
  "displayName": "라떼 닥스훈트",
  "description": "라떼색의 보송한 장모와 긴 귀, 짧은 다리가 귀여운 닥스훈트.",
  "spriteVersionNumber": 2,
  "spritesheetPath": "spritesheet.webp"
}
```

`spritesheetPath`는 `pet.json`이 있는 폴더를 기준으로 한 상대 경로입니다. 다른 펫으로 수정해 배포할 때는 기존 펫과 구분할 수 있도록 `id`, 표시 이름, 설치 폴더 이름을 함께 변경해 주세요.

## 편집 시 유지할 사항

- 전체 이미지 크기, 격자, 프레임 크기를 유지합니다.
- 동작별 사용 열과 프레임 수를 유지합니다.
- 투명 배경을 유지해 펫 주변에 사각형 배경이 생기지 않게 합니다.
- 시선 프레임은 위 표의 각도 순서로 배치합니다.

이 팩은 Codex에 내장된 imagegen으로 생성한 래스터 이미지입니다. 벡터 도형이나 관절 리그는 포함하지 않습니다. 에셋, 메타데이터, 문서에는 저장소의 [MIT 라이선스](../LICENSE)가 적용됩니다.
